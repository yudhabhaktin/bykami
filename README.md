# studio-landing

Landing page for a self-photo studio / photo booth business.

## Layout

```
refs/screenshots/   Reference captures (gitignored — see below)
design/             Derived design direction: palette, type, spacing, layout notes
```

## Reference material

`refs/screenshots/` holds captures from Instagram accounts used as visual
reference — currently [@studiobykami](https://www.instagram.com/studiobykami/),
a self-photo studio in Banyuwangi.

These are **inputs to a design process, not assets**. They stay gitignored:

- The photos are the account owner's copyright. They must not ship on the site.
- What carries forward is `design/direction.md` — palette, type, spacing, and
  layout structure derived from looking at them.

Anything on the finished landing page must be original, licensed, or the
client's own photography.
